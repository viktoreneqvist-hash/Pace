# Frontend provenance

The initial interface was exported from:

- Repository: `https://github.com/viktoreneqvist-hash/pace-ui-prototype`
- Commit: `0c6a3e6`
- Imported: 2026-09-17

The source was converted from Lovable's TanStack Start/Cloudflare-oriented
runtime to a client-only Vite application. Pace's FastAPI process is the only
production server. Lovable-specific error reporting, server runtime, cloud
deployment configuration, and external integration hooks are intentionally not
part of the integrated application.
