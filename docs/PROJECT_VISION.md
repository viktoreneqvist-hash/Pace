# AI Running Coach

## Purpose

Build an AI-powered running and cycling coach that can:

- Analyze training data

- Track long-term progress

- Detect fatigue and injury risk

- Create personalized training recommendations

- Explain recommendations using sports science

## Secondary Goal

Learn:

- Software engineering

- Databases

- APIs

- AI engineering

- Agent architecture

- Retrieval systems

- Memory systems

## Success Criteria

The system should eventually:

- Import training data automatically

- Store historical data

- Analyze training load

- Create training plans

- Answer training questions

- Remember user history

## Target User

Initially:

- Viktor

Later:

- Other endurance athletes
